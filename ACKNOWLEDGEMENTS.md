# Acknowledgements

MihoTerm is an independent implementation built against the public Mihomo
external-controller API.

The project is inspired by:

- [JohanChane/clashtui](https://github.com/JohanChane/clashtui) for rich
  terminal interaction patterns;
- [potoo0/mihomo-tui](https://github.com/potoo0/mihomo-tui) for a focused
  Mihomo API client scope;
- [spencerwooo/mihoro](https://github.com/spencerwooo/mihoro) for lightweight
  lifecycle ideas;
- [Ratatui](https://github.com/ratatui/ratatui) and
  [Crossterm](https://github.com/crossterm-rs/crossterm) for the terminal
  application ecosystem.

Inspiration does not imply affiliation or endorsement. If code is reused in
the future, its original copyright and license notices must be preserved in
the same change.
